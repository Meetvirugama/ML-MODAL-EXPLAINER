## 🎨 Customization Examples

### Change Colors (30 seconds)
Edit `config.js`:
```javascript
colors: {
  primary: "#ff0000",    // Red
  accent: "#ffff00",     // Yellow
}
```

### Change Timing (10 seconds)
Edit `config.js`:
```javascript
sceneSwitchDuration: 5000,  // 5 seconds per scene
```

### Change Particles (10 seconds)
Edit `config.js`:
```javascript
particles: {
  count: 10000,  // More particles
  size: 0.3,
}
```

All changes take effect immediately when you restart!
