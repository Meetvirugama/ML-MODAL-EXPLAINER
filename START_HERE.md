## 💡 Customization Tips (Easy!)

### Change Colors (5 seconds)
Edit `config.js`:
```javascript
colors: {
  primary: "#ff0000",    // Your color here
  accent: "#ffff00",
}
```

### Change Timing (5 seconds)
Edit `config.js`:
```javascript
sceneSwitchDuration: 10000,  // 10 seconds per scene
```

### Change Particles (5 seconds)
Edit `config.js`:
```javascript
particles: {
  count: 10000,  // More particles
  size: 0.3,
  opacity: 0.9,
}
```
